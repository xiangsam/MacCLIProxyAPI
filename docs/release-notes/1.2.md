## 本版本

### 防止睡眠/待机后被系统自动杀死

- 应用启动时调用 `ProcessInfo.disableAutomaticTermination`，退出 AppKit 对「无窗口后台应用」的自动终止判定，不再被系统当作空闲进程回收。
- `applicationShouldTerminate` 收紧为白名单：仅注销 / 重启 / 关机（系统 `kAEQuitReason`）或应用内明确的退出操作（菜单栏「退出」、⌘Q / App 菜单退出）放行，其余一律拒绝。

### 降低后台轮询频率

- 无主窗口（纯菜单栏）时的状态轮询间隔从 60 秒降到 30 分钟，减少后台唤醒次数；打开主界面时仍是 10 秒，不受影响。

### 发布流水线

- 新增 GitHub Actions：推送 `v*` 标签即可自动编译、按标签同步版本号、打包 dmg/zip 并发布 GitHub Release。
