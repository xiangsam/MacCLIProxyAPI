- 区分上游 API、订阅账号与客户端接入配置；“接管前配置”明确表示备份快照。
- 同名 GPT 来源改为正常路由、仅订阅、仅 API 三选一，与优先级和调度方式分开；切换客户端配置不再修改全局策略。

- 会话库策略与旧会话迁移、撤销迁移分开操作。
