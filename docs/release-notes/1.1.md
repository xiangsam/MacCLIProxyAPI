## 本版本

### Codex 本机 CPA · auth.json

- 启用 Codex「本机 CPA」时，若 `~/.codex/auth.json` 不存在，写入 `auth_mode=apikey` / `OPENAI_API_KEY=cpa` 占位，避免 Codex 因缺少登录文件去走 ChatGPT 登录。
- 切换到官方 / 自定义 /「默认」时，仅当该文件仍是上述占位内容才删除，ChatGPT OAuth 的 `auth.json` 不会被动。
- 远程 SSH 启用或切走 Codex CPA 使用同一套规则。

### 修复 Codex Desktop 自定义模型

- Codex「本机 CPA」卡片增加「修复 Codex Desktop 自定义模型…」。二次确认后删除（若存在）`~/.codex/auth.json`、`.codex-global-state.json`、`.codex-global-state.json.back`，再写入 CPA 占位 `auth.json`。用于 Desktop 缓存导致自定义模型不出现的情况；会丢失 ChatGPT 登录态，完成后需重启 Codex Desktop。
