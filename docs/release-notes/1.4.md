## 升级方式

先安装本版本应用，再到「版本」页点击「安装兼容内核 / 更新兼容内核」，安装 **CPA 8.0.21-mac.1**，然后启动内核。
仅更新桌面应用不会替换已安装的内核；直接 `/v1/models` 的归属修复需要兼容内核生效。

## 修复与兼容

- 修正原生 Responses API-key 模型的 `/v1/models` 归属：DeepSeek 官方端点返回 `deepseek`；OpenAI 保持原值，自定义网关可用模型的 `owned-by` 指定归属。
- 保留原生 Responses 执行器、工具请求、模型别名和路由优先级。
- 兼容 CPA v8 的客户端密钥、上游凭据分组、模型列表、GUI 设置及思考别名；普通保存保留每个 key 的继承和覆盖设置。
- 升级时迁移旧配置，保留密钥、OAuth 文件、模型、路由与未知字段。早期 v8 的 OAuth 设置路径在普通保存时保留，升级兼容内核后迁移到新的 client / upstream 路径。
- 原始配置备份保存在 `~/Library/Application Support/com.maccliproxyapi/config-backups/`，不会随下一次安装清理；无效配置中止安装，替换失败恢复旧安装。
- 默认更新渠道改为带归属补丁的兼容内核。指定纯数字版本仍可安装官方内核；官方内核不包含此补丁。降级需先恢复对应版本的配置备份。
